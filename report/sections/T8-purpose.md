# 一、实验目的

本实验基于 RISC-V 64 体系架构（Sv39 分页机制）与 uCore 操作系统内核，系统性构建物理内存探测、物理页帧管理、多策略连续内存分配以及内核小对象分配的端到端软硬件协同认知：

1. **掌握 RISC-V 体系架构下的虚存映射与物理内存基石**：
   - 深入理解 Sv39 分页硬件机制，掌握虚拟地址（Virtual Address）、物理地址（Physical Address）及物理页号（PPN）之间的转换数学关系与硬件 MMU 多级页表遍历原理。
   - 理解内核高半核虚拟地址空间布局（`KERNBASE = 0xFFFFFFFFC0000000`），掌握启动阶段利用 1 GiB 巨页映射建立的内核常驻内存映射，以及利用固定物理偏移 `va_pa_offset` 进行高位虚拟地址与实际物理地址平滑换算的工程设计。

2. **掌握基于固件与设备树（DTB）的物理内存动态探测与初始化流程**：
   - 掌握操作系统通过 OpenSBI 固件接口（寄存器 `a1`）解析 Device Tree（设备树）获取硬件物理内存基址（`DRAM_BASE = 0x80000000`）与内存容量的通用方法，摆脱对静态硬编码物理地址的依赖。
   - 理解并实现物理内存生命周期管理的关键起点 [`page_init()`](file:///home/nagilix/Code/NKU-OS-LAB/code/kern/mm/pmm.c#L137-L188)，掌握全局物理页描述符数组（[`struct Page`](file:///home/nagilix/Code/NKU-OS-LAB/code/kern/mm/memlayout.h#L34-L39)）的构建、物理页号映射关系的确定、保留内存（OpenSBI、内核镜像、Page 描述符数组本身）的保护与隔离，以及可用物理内存空闲区域的精确划定。

3. **掌握连续物理内存页面分配与释放算法的架构与工程实现**：
   - 深入理解物理内存分配器抽象接口 [`struct pmm_manager`](file:///home/nagilix/Code/NKU-OS-LAB/code/kern/mm/pmm.h#L14-L44) 的面向对象设计模式，实现分配算法与内核通用内存管理框架的解耦。
   - 剖析并实现经典内存分配算法：
     - **First-Fit（首次适应）**：掌握双向循环链表维护物理块升序排列的机理，理解双向空闲块合并的相邻性数学判定与边界控制；
     - **Best-Fit（最佳适应）**：掌握在全链表中检索满足请求且尺寸最小的空闲物理块的策略，权衡内部碎片抑制与遍历时间开销；
     - **Buddy System（伙伴系统）**：掌握按 $2^k$ 阶块组织的二叉树伙伴结构，理解内存块的动态切分与伙伴页算术快速合并逻辑，兼顾分配效率与碎片控制。

4. **掌握内核级小对象内存分配器（SLUB/Slab）的机理与实现**：
   - 深刻理解以 4KB 物理页为基本分配粒度所引发的严重内部碎片问题。
   - 掌握 SLUB 分配器的核心思想：基于按对象尺寸分级（Cache）、无描述符外部开销、页内空闲对象单向链表串联的精简设计，掌握内核对象快速申请（[`kmalloc`](file:///home/nagilix/Code/NKU-OS-LAB/code/kern/mm/slub.h#L39)）与释放（[`kfree`](file:///home/nagilix/Code/NKU-OS-LAB/code/kern/mm/slub.h#L40)）的高效闭环。

5. **具备软硬件联合仿真环境下的指令级分析与排障能力**：
   - 熟练使用 GDB 挂载 QEMU 模拟器进行指令级断点调试与内存状态核查；
   - 结合分支任务，通过 GDB 调试 QEMU 源码，追踪 RISC-V MMU 的硬件页表遍历调用链路与 TLB 命中/未命中逻辑，打通硬件执行与操作系统软件抽象之间的认知壁垒。

6. **践行基于“契约驱动与提示词工程”的高效 AI 协同研发范式**：
   - 规范四段式契约（`[PROMPT]` / `[RELY]` / `[GUARANTEE]` / `[SPECIFICATION]`），严格约束 AI 编程工具的代码边界与上下文信任域；
   - 坚持人对内核底层代码 100% 的可解释性与防御性审查（Defense-Readiness），杜绝 AI 幻觉引入的隐蔽内存泄漏与野指针崩溃。
