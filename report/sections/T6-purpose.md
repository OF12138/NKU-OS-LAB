# 一、实验目的

本实验基于 RISC-V 64 体系架构与 uCore 操作系统内核，通过模拟器仿真与底层跟踪，系统性建立从裸机加电、固件引导到操作系统接管硬件的端到端认知：

1. **掌握 RISC-V 体系架构的特权级机制与固件交接规范**：
   - 深入理解 Machine Mode（M 态）与 Supervisor Mode（S 态）的硬件特权隔离语义。
   - 理清硬件复位向量（0x1000）、M 态固件（OpenSBI 0x80000000）以及 S 态内核（0x80200000）之间的跳转规范，掌握通过通用寄存器传递参数（`a0` 传递 Hart ID、`a1` 传递 DTB 设备树地址）的交接契约。

2. **理解内核内存布局与重定位机制**：
   - 掌握链接脚本在确定内核物理加载地址（LMA）与虚拟链接地址（VMA）中的关键作用。
   - 深入理解操作系统从裸机物理内存入口平滑过渡到高位内核空间的基础原理。

3. **掌握底层硬件状态与上下文切换架构**：
   - 熟悉 RISC-V 核心控制与状态寄存器（`mstatus`/`sstatus`、`stvec`、`scause`、`sepc`）的硬件更新机制。
   - 剖析固件如何通过 `mret` 指令安全降权切换至 S 态，以及操作系统如何通过 `ecall` 指令发起 SBI 服务调用以实现底层字符输出。

4. **具备裸机环境下的 GDB 联合仿真与指令级排障能力**：
   - 熟练运用 GDB 通过 Remote 端口连接 QEMU 模拟器，在无操作系统支持的裸机环境下，针对汇编指令级断点、寄存器状态检查及内存倾倒展开精准跟踪与分析。# 一、实验目的
